SIEVE

NSDI ’24 · Community Award

How it works NSDI’24 Paper Code Blog post

How does SIEVE work?

  1. On a hit, SIEVE sets the object’s visited bit. Nothing moves.
  2. On a miss, the new object is inserted at the head of a single FIFO queue.
  3. To evict, a hand walks from the tail toward the head. It clears the visited bit of each object it passes and evicts the first object whose bit was already clear, then stays there for the next eviction.

Key Features

Simplicity

SIEVE is easy to implement and can be easily integrated into existing systems.
